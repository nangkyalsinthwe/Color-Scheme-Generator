# Color Scheme Generator

A web application for generating color palettes based on a selected seed color and scheme mode (such as Monochrome, Monochrome-dark, Monochrome-light, Analogic, Complement, Analogic-complement, and Triad).

- **Live Demo:** https://nangkyalsinthwe.github.io/Color-Scheme-Generator/
- **Built With:** HTML5, CSS3, JavaScript
